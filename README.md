# pastel-handdrawn-photo

一个可复用的 Agent Skill（当前版本 v1.5.0）：用户上传食物、人物、宠物、鲜花、商品或日常物件照片后，自动生成“主体保留真实摄影质感 + 主体外轮廓细白色手绘描边 + 背景和周边物件转为彩色手绘插画 + 少量手写日记文案与 doodle 装饰”的混合媒介图片。

**v1.2.0 增加强制主体描边规则：** 食物、人物、宠物、鲜花和商品等主要主体均需沿整体外轮廓添加纤细、自然、略不均匀的白色手绘线。食物描食物本体，不误描盘子；人物描整体剪影，不描五官、不改变面容。主体仍保持真实摄影质感。

**v1.1.0 增加可编辑文字工作流：** 新增的手写日记文案不再烘焙进图片，而是作为独立图层放在自包含 HTML 编辑器中。用户可以点击文字选中、修改文案、拖动位置、调整颜色/字号/角度，最后导出合成 PNG。

**v1.3.0 新增主体驱动的自适应彩色手绘环境：** 每次先分析主体代表色、冷暖/明度、材质、主题和场景情绪，再决定背景配色、相关道具、小装饰、绘画媒介比例与留白。背景不再固定套用粉紫色或通用模板；环境内容必须与主体和原图场景相关，统一笔触并始终衬托主体。


**v1.4.0 新增 Torn Paper Reveal｜撕纸揭示拼贴模式：** 用户可选择把未经处理的原始照片放在整张画布左上角，约占总面积 2/5；其余约 3/5 展示同一张照片经本 Skill 处理后的最终效果。两部分通过自适应的不规则手工撕纸边缘衔接，包含自然纸纤维、轻微层次和柔和投影。该模式为可选模式，原有单图输出保持不变；拼贴模式中的新增文字仍作为独立图层编辑。

## 文件结构

- `SKILL.md`：触发条件、食物/人物等主体处理规则、强制白色轮廓描边、主体驱动的自适应环境规则、Torn Paper Reveal 撕纸拼贴模式、视觉规则、分层生成流程、编辑器交付规范。
- `editor-template.html`：可离线运行的轻量编辑器模板。
- `build_editor.py`：将无文案底图和文字数据嵌入模板，生成可直接打开的 `edit.html`。
- `text-items.example.json`：可编辑文案数据示例。

## 使用方式

将整个 `pastel-handdrawn-photo` 文件夹复制到支持 Agent Skills 的工具的 skills 目录中。重新加载该工具或开启新会话后，上传图片即可触发。具体安装目录以所用工具的 Skills 文档为准。

## 自适应环境规则速览

- 色彩：从主体提取代表色，按冷暖、明度和饱和度选择协调的辅助色；Pastel 是质感倾向，不是固定色板。
- 内容：优先转绘原图环境，并只补充少量与主体直接相关的小元素。
- 风格：根据主体材质和场景调整彩铅、蜡笔、粉彩、水彩的比例，确保全图笔触统一。
- 氛围：根据原图可见线索调整装饰密度、背景复杂度和留白；主体始终是视觉中心。
- 禁止：随机冲突配色、无关道具堆砌、固定背景模板、背景喧宾夺主。

## Torn Paper Reveal 拼贴模式速览（v1.4.0）

- 仅在用户明确要求原图与最终效果同画布展示时启用；默认单图模式不变。
- 左上角保留真实、未经改造的原始照片纸片，约占整张画布总面积 40%（不是宽度/高度的 40%）。
- 其余约 60% 展示同一张照片经过 Skill 处理后的最终效果，主体必须清楚完整。
- 两部分之间采用自适应的不规则手工撕纸边缘，带自然纤维、纸层厚度和轻微阴影；禁止直线分割或普通矩形拼接。
- 手写文字仍是可编辑独立图层，默认只放在最终效果区域，不烘焙进底图。

## 主体描边规则速览

- 食物：沿食物本身最外侧可见边缘描白线，不逐一描绘配料、纹理，也不默认描盘子。
- 人物：沿头发、头肩、衣服、手臂和身体整体外缘描白线；保留面容与表情，不描五官。多人照片尽量逐人沿可见轮廓描边。
- 宠物、鲜花、商品：描整体可识别外轮廓，不追逐每根毛发、每片花瓣或内部细节。
- 线条要纤细、白色、略不均匀、贴合边缘；不能成为粗厚贴纸边框或灰白光晕。

## 每次生成的推荐交付

- 若用户选择 Torn Paper Reveal 模式，`artwork-base.png` 应是包含左上原图纸片、撕纸过渡和其余最终效果区域的完整拼贴画布；否则按原有单图模式交付。

- `artwork-base.png`：主体真实、周边彩色手绘，但不含新增日记文案的底图。
- `edit.html`：自包含编辑器，打开即显示本次底图和文字图层。
- `final.png`：可选，初始文字合成版。

主体白色描边会作为底图视觉的一部分生成；当前编辑器主要用于独立编辑手写文字，描边本身不是可点击的编辑图层。

## 编辑与导出

1. 在浏览器中打开 `edit.html`。
2. 点击画面中的手写文字，即可在编辑栏中修改；也可以拖动文字调整位置。
3. 可调整颜色、字号和旋转角度，也可新增或删除文字。
4. 点击“导出 PNG”，下载修改后的完整成品，导出分辨率与底图原始分辨率一致。

## 构建自包含编辑器

在本目录中执行：

```bash
python3 build_editor.py \
  --image artwork-base.png \
  --texts text-items.json \
  --output edit.html
```

`text-items.json` 可以是一个数组，也可以是包含 `textItems` 数组的对象。每个文字对象使用 0–1 归一化坐标 `x`、`y`、`maxWidth`，字号 `fontSize` 使用底图原始像素单位。更多字段见 `text-items.example.json`。

编辑器不依赖外部 CDN 或网络服务，字体使用本机可用的手写/楷体字体回退。不同设备的字体可能略有差异。


**v1.5.0 强化全模式手写文字规则：** 单图与 Torn Paper Reveal 拼贴模式都必须呈现 2–4 处与照片相关的手写日记短句。构图阶段预留文字区域；文案作为独立可编辑图层叠加；最终成品预览必须实际显示文字。不得因主体放大、拼贴布局或留白不足而省略文案，也不得只交付无文案底图。

## 手写文字强制规则速览（v1.5.0）

- 单图模式和 Torn Paper Reveal 模式均必须有 2–4 处手写日记短句/词组。
- 底图生成前先规划文字留白区；若空间不足，调整构图和装饰密度，不得省略文字。
- 新增文字必须作为独立可编辑对象，不能烘焙进 `artwork-base.png`。
- 最终预览必须显示初始文案，并交付 `final.png`；不能只展示无文案底图。
